Lobe formation

a new architecture for deep learning

TLDR; — Inspired by MoX architectures. To mitigate overfitting we propose a method to boost the signal to noise ratio. We partition the model into filter lobes followed by classfier/regression lobes (classify) to partition the model into sub-topologies. Filters amplify residual signals to successor nodes by routing related signals into those lobes. Higher order nodes either create higher order features or estimate latent effects using residual paths.

NoneTLDR; what is Lobeformation?

ML Models can easily learn common signals in the data. But when signals are sparse, the noise (ngrams generated by chance) will quickly overwhelm the signals.

Lobeformation is an idea, Inspired by mixture of experts architectures, and to mitigate overfitting we need to increase the signal to noise ratio. One way to do this is to partition the model into sub-topologies which I call lobes. then amplify the signal in each lobe by routing related signals into those lobes.

More Data

The simplest remedy is to get more data. With more data the more of the signal should overcome more of the noise because the signal is adaptive while the noise being random is not. What I mean is that the signal is a consistent pattern while the noise is a random pattern. If we double the data, we expect to double the signal while the noise averages out.

Why do we need to double the model - perhaps we don’t but the model has a certain capacity. If we have a long signal it will need to compete with shorter noise patterns, some of which will be more frequent. So we unless we can avoid fitting noise aggressively we need to also increase the capacity of the model.

Lobeformation

My idea is to consider a model as a topology - connecting inputs to outputs. By partitioning the model into sub-topologies which I call lobes and routing related signal to those partitions I hope to make better use of the model capacity and increase the signal to noise ratio in these specific sub topologies.

An added bonus is that the model should be able to learn faster.

Interlude on random processes.

The main challenge in the abstract is how to discriminate between the signal and the noise. The basis here should be statistical.

We can think of the corpus as being generated by random processes

The data generating process has two components:

  • a signal generating process that has a distribution over bit strings. This process uses a subset of the possible patterns in the data
  • a noise generating process using some distribution over bit strings.

The data generating process generates signals that follow some subset of possible patterns.

Noise has all patterns, is random, and is generated by a noise generating process.
